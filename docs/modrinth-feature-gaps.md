# Moss and the Modrinth server UI

Compared on 2026-09-23 against the **vendored source at `eacc38fb51ad7ef5c66714afebd66e24b4ec9301`**, not a claim about every feature in Modrinth's live service. This is a feature-level inventory of missing or partial server-management flows. Launcher-only functions, storefronts, and unrelated project pages are excluded. The launcher and website both wrap these shared UI layouts; having the UI source does not provide its Archon/Kyros hosting backend.

Moss already has local accounts with mandatory 2FA, server creation/world ZIP import, power controls, console, resource cards, basic files and backups, Vanilla/Fabric/Paper installation, uploaded JAR selection, Modrinth mod/plugin search and installation, enable/disable/delete content, and custom icons for both Moss and Minecraft. Moss also has its own opt-in application updater.

Do not infer scheduling or crash auto-restart support from unused UI strings: the general-settings source explicitly comments out its auto-restart option as unimplemented. Scheduled backups, a player ban/whitelist dashboard, multi-host orchestration and container isolation may be useful Moss additions, but this comparison does not claim they are working features in the pinned Modrinth UI.

Suggested implementation order: a friendly properties editor; backup management/downloads; content updates and modpacks; per-server permissions/audit history; advanced runtime/software options. Automatic **Moss application updates** do not update Minecraft, mods, plugins or modpacks.
